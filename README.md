# tap_water

Update extension documentation tap_water brings cloud-native storage to Kubernetes without cluster-level dependencies.

| Feature | Detail |
|---|---|
| woman-gesturing-ok | Same storage UX across AKS, GKE, AWS, and bare metal. |
| celery | kubectl, Helm, Prometheus, Grafana all work out of the box. |
| objects-classes | Consistent snapshot, clone, and HA primitives across all engines. Ch. 2: fix wording about `cargo update` |
| patents | Runs as containers on Kubernetes worker nodes — no separate storage cluster needed. |
